# Scotty v0.4.0 — Security updates, a resizable sidebar and keyboard shortcuts

This release updates Next.js and zod for security advisories, fixes fast typing in the search box, and includes four community features.

## Security

- **Next.js 16.4.1 and zod 4.6.7.** These clear two critical and two high advisories reported against Next.js 16.3.8 and zod 4.4.3. Scotty uses neither `use cache` functions nor Server Actions, and already pins a patched `sharp`, so the three Next.js advisories weren't reachable in practice. Next.js recommends upgrading regardless. `npm audit --omit=dev` now reports no vulnerabilities. (#110)
- **A security policy.** `SECURITY.md` explains how to report a vulnerability privately through GitHub, and what is in scope for a local web app. Only the latest release (0.4.x) receives security fixes. (#112)
- Routine dependency updates: `markdown-it` 14.3.3, plus dev-toolchain updates that remove an unused Express tree from the shadcn CLI.

## Fixes

- **Typing fast in the search box keeps every character.** On Next.js 16.4.1 the URL reached the search box one render late, so fast typing dropped characters ("hello world" became "hld"). The box now keeps what you typed until the URL catches up. Back, Forward and Clear still update it. (#110)

## Improvements from the community

- **Resize the sidebar** by dragging its right edge, between 180px and 400px. The width is remembered per browser, like the detail drawer's. (#98, @aspiers)
- **Cmd/Ctrl+Enter submits text fields** throughout the app: the Needs You reply, the gate approval note, the drawer's comment box and title, the Settings fields and the Publish site title. Plain Enter is unchanged. (#97, @aspiers)
- **Press Y to copy a bead's ID**, from the selected Board or List card or the open detail drawer, ready to paste into a terminal or chat. (#100, @aspiers)
- **The detail drawer shows a links & attachments strip**, gathering every link and attachment from the bead's description, notes, design and comments, like the Needs You cards do. (#68, @aspiers)

Thank you @aspiers!

## Install this release

**Homebrew** (macOS or Linux):

```sh
brew install brendan-appstart/tap/bead-me-up-scotty   # new install
brew upgrade bead-me-up-scotty                        # existing install
```

**From source:** prerequisites are a supported Node.js version (Node 20.9+; Node 22 or newer recommended), npm, and the Beads `bd` CLI for live project data. Without `bd`, Scotty runs with demo data.

```sh
git clone --branch v0.4.0 https://github.com/brendan-appstart/bead-me-up-scotty.git
cd bead-me-up-scotty
npm ci
npm run build
npm run serve
```

Open `http://localhost:3000`. A detached checkout of the release tag is expected and is supported by the stable updater.

## Update an existing installation

**Homebrew:** run `brew upgrade bead-me-up-scotty`, then restart `scotty`. Use Homebrew rather than the in-app "Update now" button.

**Existing Git checkout:** use the in-app update notice, or, after committing or stashing local source changes, run from the app's checkout:

```sh
git fetch origin tag v0.4.0
git merge --ff-only 'v0.4.0^{commit}'
npm ci
npm run build
```

Restart Scotty.

**Global copy, source download or Docker:** build a fresh checkout of this release, then reinstall the global copy, replace the source installation, or rebuild the image. Restart Scotty or recreate the container.

Updating changes Scotty's source and dependencies, not your Beads issue database.

## Scope and validation

This is a source release, installed through Homebrew, Git/source or Docker. It does not publish an npm package. Beads data stays local and is not modified by the release process.

Before merging, the combined tree (the dependency updates, #68 and the security policy) was validated on isolated servers with intercepted browser fixtures and disposable `bd` repositories. Every regression script passes in its intended server mode. That includes the new `test-search-typing`, which fails without the search fix. The timing-sensitive scripts (`test-search-typing`, `test-copy-id`, `test-assignee`, `test-url-navigation` and `test-keyboard`) each passed four or five repeated runs. The production build and TypeScript checks pass. Lint reports no errors and the one existing navigation warning. The Homebrew formula installs from source and passes `brew audit --strict` and `brew test`.
