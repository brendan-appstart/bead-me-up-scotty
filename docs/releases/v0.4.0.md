# Scotty v0.4.0 — Graph filtering: closed hidden by default, search, assignee, labels

## What's changed

- The Dependency graph now **hides closed and unlinked beads by default**: the **Live dependencies only** toggle starts checked. Uncheck it to bring back the full graph (closed and unlinked beads included).
- A new **search box** narrows the graph by bead **id, title, labels, or assignee**.
- New **Assignee** and **Labels** multi-select filters, plus a **Clear · n** control to reset the active filters.
- Scoping to an epic keeps the epic visible as an **anchor** even when it doesn't match the filters, so scope context is retained.
- The canvas **re-fits** when the visible set changes, and the empty state now offers **Clear filters** or **Show all beads** depending on what hid the graph.
- The **"N hidden by filter"** count now includes beads removed by the search/assignee/label filters, not just the live-only prune.

Stable updates now track this project's repository (`giangdhwhtbr/scotty`).

## Install this release

Prerequisites: a supported Node.js version (Node 20.9+; Node 22 or newer recommended), npm, and the Beads `bd` CLI for live project data. Without `bd`, Scotty can run with demo data.

```sh
git clone --branch v0.4.0 https://github.com/giangdhwhtbr/scotty.git
cd scotty
npm ci
npm run build
npm run serve
```

Open `http://localhost:3000`. This checks out the release tag; a detached checkout is expected and supported by the stable updater. The supervised launcher restarts automatically after a successful in-app update.

For a global `scotty` command, follow the README's `npm link` or global-copy instructions after building this release. This release does not publish a package to the npm registry or include a desktop installer.

## Update an existing installation

**Existing Git checkout:** first commit or stash local source changes, then run from the app's checkout:

```sh
git fetch origin tag v0.4.0
git merge --ff-only 'v0.4.0^{commit}'
npm ci
npm run build
```

Restart Scotty. If Git refuses the fast-forward, preserve your work and use a separate release checkout rather than resetting your branch. Once on v0.4.0, later published versions appear through the stable update channel.

**Global copy or source download:** build a fresh checkout of the chosen release using the install steps, then repeat `npm install -g .` for a global copy, or replace the source installation. Restart Scotty. The in-app notice links to these instructions; it does not attempt a Git update in a non-Git installation.

**Docker:** rebuild the image from the release source and recreate the container using your existing configuration and persistent mounts. The in-app update notice is informational; update the image through your Docker workflow. See the README for container setup.

The update feature updates Scotty's source and dependencies, not your Beads issue database. Back up your local project data as usual.

## Scope and validation

This is a source release, with installation through Git/source or Docker. It does not publish an npm package or a desktop installer. Beads data stays local and is not modified by the release process.

Validation: `tsc --noEmit` and the production build pass; lint reports no errors and one pre-existing navigation warning in `hooks/use-notifications.ts`. The graph regression scripts (default pruning, recursive epic scope, and dependency spotlight) pass against an isolated demo server, and the update-flow regression script passes. The full 27-script suite was not re-run for this release.
